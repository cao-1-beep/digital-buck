## 四、模拟前端系数(全部从原理图的电阻网推出来)

| 量 | 公式 | 量程 |
|:--|:--|:--|
| **输出电流** | `I[A] = (V_adc ? 0.3765) / 0.4706` | **?0.80 ~ +6.21A**(零电流 ≈ ADC 467) |
| **输入电压** | `Vin = V_adc × 11` | 36.3V |
| **输出电压** | `Vout = V_adc / 0.2481` | 13.3V |
| **温度** | `ratio = V_ntc / Vin`,`R_NTC = 68 × (1/ratio ? 1)`,`T[K] = 1/(1/298.15 + ln(R_NTC/10000)/3950)` | 0 ~ 150°C(≈22 码/°C) |

**三点说明:**
- **电流偏置 0.3765V 是算出来的,不是猜的**:1.2V 基准经 `R3(100K)/R5(1k)` 往 IN+ 注 23.5mV,再被增益放大 → 增益 51 时正好是 1.2V,你把增益改成 16 之后就变成 **0.3765V**。这也让**负向量程从 ?2.4A 缩到 ?0.80A**(你采的是单向负载电流,够用)。
- **上电会做电流零点标定**(输出关断时采 8 轮取平均),所以 LMV321 的输入失调(±7mV ? ±233mA)被吃掉。
- **NTC 是比例式**(以 VIN 为参考),`Vin` 自动消掉 —— 但 0°C 以下分辨率很差,所以**只用它做过温,不做低温判断**。

## 五、控制架构(这是相对原代码改动最大的地方)

```
电压外环 PID(5kHz) ──Icmd──> 电流内环 PID(50kHz) ──Duty──> TIM1_CH3(PA10) ──> RT9624 ──> 半桥
        ↑ Vout(PA7)                    ↑ Iout(PA6)                                     ↓
        └──────────── ADC1 四通道,TIM1 TRGO 触发 + DMA 环形 ?──────────────────────── L1/Vout
```

| 层 | 频率 | 干什么 | 为什么 |
|:--|:--|:--|:--|
| PWM 更新中断 | **100kHz** | 读电流(2 次浮点运算)+ **逐周期限流整数比较** + 分频计数 | 限流要快 |
| 电流内环 | **50kHz** | PID → 占空比 | 采样链带宽 64kHz(运放 GBW/增益),50kHz 采样终于是有意义的 |
| 电压外环 | **5kHz** | PID → 电流指令 | 电压环本来就慢 |
| 主循环 | — | Vin/Vout/NTC 换算、按键、OLED、Flash | 慢变量,不在中断里做 |

**为什么必须分频**:原代码在 10μs(720 周期)的预算里做 ADC 的浮点平均(12 次 int→float + 12 次加)+ 保护 + PID,按实际调用链估算 **15~29μs,超预算 1.5~3 倍**。分频后中断里最坏约 **12~15 次浮点运算 ≈ 300~400 周期**,余量约 2 倍。

> **上板后请用一个空闲 GPIO 在中断进出处翻转,示波器量实际宽度。** 估算不等于实测。

## 六、保护(全部软件)

| 层 | 阈值 | 动作 | 响应 |
|:--|:--|:--|:--|
| ① 逐周期限流 | **2.0A**(可改,0.1~2.0) | 本周期占空比压 0,下周期自动恢复 | **10μs** |
| ② 硬跳闸 | **3.2A**,连续 3 个周期 | 锁存 + 关输出,OLED 报 `OCP` | 30μs |
| ③ 输入欠压 | < 13.0V(消抖 50ms) | 关输出;回到 13.5V 自动清位(输出不自动开) | ms |
| ④ 输入过压 | > 26.5V(消抖 20ms) | 同上 | ms |
| ⑤ 输出过压 | > VSET×1.10 或 > 11.0V(3ms) | 锁存 | ms |
| ⑥ 过温 | **> 85°C**(100ms) | 锁存;回落到 75°C 以下才允许清除 | 100ms |
| ⑦ 过温降额 | **70°C 起** | 限流点从 2.0A 线性收到 1.0A | 100ms |

**?? 为什么跳闸是 3.2A 而不是更高**:电感 `L1 = xr1050-680m` 的**饱和电流只有 3.8A**,而最坏工况(25V→10V/2A)的纹波是 0.88A p-p ? 半纹波 0.44A。`3.2 + 0.44 = 3.64A < 3.8A`,**故障时电感也不会饱和**。跳闸点若设到 3.6A,峰值会到 4.04A,**超过饱和点** —— 电感一旦饱和,后面电流就失控了。

**本板没有硬件过流比较器**,所以过流全靠上面 ① ② 两层。台架必须用限流电源。

## 八、台架调试顺序

> 前 3 步不要接负载。

1. **只上 3.3V**(可从 P3.1 供)。看 OLED 是否亮、显示 `SET 5.00V CV`。不亮 → 先查 PB6/PB7 与上拉。
2. **量 PA10 静止电平**:应为**低**(MOE=0 + OSSI=1 ? 主动拉低)。若悬空/高 ? 查 `PWM_Init` 的 OSSI 配置。
3. **按 S3 开机**,示波器看 PA10:应有 **100kHz 方波**,占空比随软启动从 0 升到约 42%。频率不对 → 查 Y1(应为 8MHz)。
4. **电流零点**:开机后 OLED 的 `IO` 应显示 ≈ 0.00A(上电已自动标定)。若明显非零 → 用 `ADC_GetZeroRaw()` 在 Keil Watch 里看,正常约 467。
5. **接限流电源(先限到 0.2A)、不接负载**,确认 Vin 读数与电源表一致(分压 1:11)。
6. **接电子负载**,从 0.2A 慢慢加,看 `IO` 读数与外部分流器是否一致。不一致就按实测改 `ADC_IOUT_V_PER_A`。
7. **PID 整定**:
   - **先内环**:`Control_SetIpid(0.05, 200, 0)` 起步,加负载看阶跃;振荡→减 Kp/Ki,太慢→加。
   - **再外环**:`Control_SetVpid(0.3, 50, 0)` 起步,同理。
   - 用 **Keil 的 Watch 窗口 + Logic Analyzer**(通过 SWD 周期性读变量)把 `duty`/`ADC_GetIout()`/`ADC_GetVout()` 画成曲线 —— **不需要额外硬件**。
8. **过温**:用热风枪或电烙铁靠近 NTC,看 OLED 温度上升、70°C 起 `IO` 上限被压低、85°C 报 `OTP` 停机。
9. **过流**:把负载设成恒流 2.5A,应看到 `LMT` 闪烁(限流在起作用),而不是跳闸;再把负载短路(经限流电源!),应在几十μs 内 `OCP` 停机。
10. **保存参数**:停机后按 S5,应显示 `SAVED`;断电重上,参数应恢复。

**我在这轮抓到并修掉的 3 个 bug(记录一下,免得你以为是"一次就对"):**
1. `ADC_Init` 里零点标定会**死等** —— 因为 TIM1 的 **TRGO 没设 `MMS`**(默认只跟软件 `UG` 位走),ADC 永远不会被硬件触发。**后果是上电即卡死。**

3. **`Protect_SetOcp` 语义冲突** —— 你的原意是"跳闸阈值",我在保护层里写成了"限流阈值"。已拆成 `Protect_SetLimit`(限流)与 `Protect_SetOcp`(跳闸)。
